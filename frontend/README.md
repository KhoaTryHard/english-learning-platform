# Frontend — Hưng

Một React web app responsive. Desktop/mobile chỉ tách layout cần thiết; feature/state/API dùng chung. Chưa có runtime/package.json trong scaffold; triển khai FE-01/02 theo W5-03 trước.

src/app: bootstrap/router/providers/layouts; src/features: nghiệp vụ; src/shared: components/API/hooks/styles/assets; tests: app-level test. Feature tests đặt cạnh feature khi code có. Stack React + TypeScript + Vite là đề xuất khởi tạo, không nâng phiên bản dự án đang có tự động.
