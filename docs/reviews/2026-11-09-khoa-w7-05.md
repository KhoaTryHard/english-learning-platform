## Handoff cho Huy — API nguồn và semantics

| API nội bộ (GET) | Caller được phép | Payload/semantics đã kiểm |
|---|---|---|
| User `/internal/v1/users/{userId}/learning-setup` | assessment, progress | `courseId`, `levelId`, `updatedAt`; nullable khi chưa setup; UUID sai400, User không tồn tại404 |
| User `/internal/v1/learners/cohort` | progress | Filter `courseId`,`levelId`; page0-based, size1–100/default100; cohort gồm BLOCKED và Learner chưa setup nếu không filter; `totalElements` theo filter, `totalLearnersGlobal` độc lập filter |
| Content `/internal/v1/courses/{id}/context` | user, assessment, progress | `courseId`,`published`,`totalLessons`,`levels`,`generatedAt`; totalLessons gồm Lesson draft/hidden, không chỉ nội dung Learner đang đọc được |
| Content `/internal/v1/courses/contexts` | progress | Page0-based, size1–100/default100; stable order theo UUID khi dữ liệu đứng yên; gồm Course draft |
| Content `/internal/v1/lessons/{id}/context` | assessment | `lessonId`,`moduleId`,`courseId`,`visibleToLearner`; Progress caller bị403 |

Host TEST: User `http://127.0.0.1:18081`, Content `http://127.0.0.1:18082`;
container-to-container: `http://user:8081`, `http://content:8082`.
Service token có audience đúng owner, public keys theo caller; private key nằm ở
service sở hữu. Internal API không gọi qua Gateway public. Probe dùng
`scripts/OwnerSourceProbe.java` và application TokenCodec; không sao chép JWT/private
key vào report. Payload thực và mã lỗi:
[source-samples.json](../evidence/khoa-w7-05-2026-11-09/source-samples.json).

User/Content/Progress/Assessment mỗi service dùng DB riêng. Không có business query
xuyên DB. Paging nhiều request và global/cohort/source reads không là snapshot giao
dịch xuyên service; `generatedAt` chỉ là thời gian response, không là snapshot token.
Lỗi nguồn hoặc payload nguồn hỏng phải báo dependency503, không dùng0 làm fallback.

Đã đọc consumer tại `413a929`: ProgressSources gọi User setup và Content context
qua HTTP, kiểm UUID/shape/count, không nuốt lỗi thành0. Progress hiện có controller
